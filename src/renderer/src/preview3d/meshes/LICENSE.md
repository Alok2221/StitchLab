# Garment mesh sources

Project meshes supplied for StitchLab preview (exported from Blender as `.glb`).
Replace any file in this folder with an updated GLB of the same name to swap a garment shell.

| File | Garment id |
| --- | --- |
| `tshirt.glb` | `tshirt` |
| `hoodie.glb` | `hoodie` |
| `trousers.glb` | `trousers` |
| `dress.glb` | `dress` |
| `tote.glb` | `tote-bag` |
| `sneaker.glb` | `sneaker` |
| `boot.glb` | `chelsea-boot` |
| `sandal.glb` | `slide-sandal` |
